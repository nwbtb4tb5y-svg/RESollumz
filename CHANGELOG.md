# Changelog

## RESollumz Prototype — 0.1.0

- Added an independent Blender loader for installing and selecting official Sollumz releases.
- Added CWBridge conversion for loose YDR, YFT, YDD and YTD resources.
- Added CodeWalker XML import through CWBridge and the existing Sollumz asset importer.
- Added YTD texture-folder and shared-folder lookup, cached extraction, reindexing, progress and cancellation.
- Added a global preference to disable CWBridge tools without changing the existing Sollumz import/export workflow.
- Validated available Gen8/Gen9 fixtures and Blender 5.2.2 XML export integration; see [known limitations](./README.md#prototype-limitations).
